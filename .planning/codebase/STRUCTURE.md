# Codebase Structure

**Analysis Date:** 2026-03-28

## Directory Layout

```text
privanote/
├── README.md                 # Project overview and usage notes
├── package.json              # App manifest, scripts, dependencies
├── package-lock.json         # Locked dependency tree
├── vite.config.js            # Vite build configuration for the renderer
├── .gitignore                # Ignored build, runtime, and local data files
├── src/                      # Application source code
│   ├── main/                 # Electron main-process code and SQLite access
│   │   ├── main.js           # App bootstrap, window creation, IPC handlers
│   │   ├── preload.js        # Preload bridge exposed to the renderer
│   │   └── database.js       # SQLite schema and CRUD helpers
│   └── renderer/             # React UI source and HTML entry
│       ├── App.jsx           # Main application component and UI state
│       ├── main.jsx          # React DOM entry point
│       └── index.html        # HTML shell used by Vite
├── data/                     # Generated SQLite database files, ignored by Git
└── dist/                     # Vite build output, ignored by Git
```

## Directory Purposes

**`src/`:**
- Purpose: All executable application source.
- Contains: Electron main-process modules and React renderer modules.
- Key files: `src/main/main.js`, `src/main/preload.js`, `src/main/database.js`, `src/renderer/App.jsx`.
- Subdirectories: `main/` for desktop runtime code, `renderer/` for UI code.

**`src/main/`:**
- Purpose: Desktop runtime and persistence layer.
- Contains: Electron lifecycle code, IPC handlers, and SQLite database logic.
- Key files: `src/main/main.js`, `src/main/database.js`, `src/main/preload.js`.
- Subdirectories: None.

**`src/renderer/`:**
- Purpose: Browser-side React application and Vite entry files.
- Contains: React components, DOM mount point, and the renderer HTML document.
- Key files: `src/renderer/App.jsx`, `src/renderer/main.jsx`, `src/renderer/index.html`.
- Subdirectories: None.

**`data/`:**
- Purpose: Local runtime storage for the SQLite database.
- Contains: `privanote.db` and SQLite journal/WAL files created at runtime.
- Key files: Database files are generated, not committed.
- Subdirectories: None.

**`dist/`:**
- Purpose: Production renderer build artifacts.
- Contains: Bundled HTML, JavaScript, and asset output from Vite.
- Key files: Built renderer entry files after `npm run build`.
- Subdirectories: Generated by the build, not maintained by hand.

## Key File Locations

**Entry Points:**
- `src/main/main.js`: Electron app entry and main-process bootstrap.
- `src/renderer/main.jsx`: React application mount point.
- `src/renderer/index.html`: HTML document loaded by Vite and the built app.

**Configuration:**
- `package.json`: Project scripts, dependencies, and Electron entry declaration.
- `vite.config.js`: Renderer build root and output directory.
- `.gitignore`: Excludes `node_modules/`, `dist/`, `data/`, and other local artifacts.

**Core Logic:**
- `src/main/database.js`: Node and attachment schema plus CRUD helpers.
- `src/main/main.js`: IPC channel registration and window lifecycle.
- `src/renderer/App.jsx`: Node list, editor, attachment UI, and local UI state.

**Testing:**
- No dedicated test directory exists in the current repo state.
- `package.json` exposes `npm test`, but it currently prints `No tests`.

**Documentation:**
- `README.md`: Short product summary, script list, and next milestone notes.

## Naming Conventions

**Files:**
- `*.js` and `*.jsx`: Runtime modules and React components.
- `package.json`: Project manifest at the repository root.
- `README.md`: Human-facing overview documentation.

**Directories:**
- `src/main/` and `src/renderer/`: Runtime-context-based grouping.
- `data/` and `dist/`: Output-oriented directories for generated state and builds.

**Special Patterns:**
- `main.js` is the Electron main-process entry file.
- `preload.js` is the only bridge file currently in the repo.
- `index.html` in `src/renderer/` is the Vite HTML root.

## Where to Add New Code

**New Feature:**
- Primary code: `src/main/` for persistence or Electron behavior, `src/renderer/` for UI behavior.
- Tests: No established tests directory exists yet; add one if testing is introduced.
- Config if needed: `package.json` or `vite.config.js` depending on the change.

**New Component/Module:**
- Implementation: `src/renderer/` for UI components, `src/main/` for runtime modules.
- Types: No shared type directory exists in the current repo.
- Tests: Not currently present.

**New Route/Command:**
- Definition: Not applicable; this repo does not use routes or CLI commands.
- Handler: Not applicable.
- Tests: Not applicable.

**Utilities:**
- Shared helpers: `src/main/` for Electron/database helpers, `src/renderer/` for UI helpers.
- Type definitions: Not currently organized as a separate directory.

## Special Directories

**`data/`:**
- Purpose: Runtime SQLite storage for app content.
- Source: Created by the app at launch via `src/main/database.js`.
- Committed: No, it is ignored in `.gitignore`.

**`dist/`:**
- Purpose: Renderer build artifacts for packaged or production runs.
- Source: Generated by `vite build`.
- Committed: No, it is ignored in `.gitignore`.

**`node_modules/`:**
- Purpose: Installed third-party dependencies.
- Source: Created by `npm install`.
- Committed: No, it is ignored in `.gitignore`.
