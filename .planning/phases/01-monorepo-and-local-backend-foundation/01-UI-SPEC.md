## Color

Distribution contract: 60/30/10 across the main desktop workspace.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `oklch(1 0 0)` | App background, primary workspace surface, page canvas |
| Secondary (30%) | `oklch(0.96 0.002 17.2)` | Cards, secondary panels, list containers, muted surfaces |
| Accent (10%) | `oklch(0.214 0.009 43.1)` | Primary CTA, current selection state, active tab/nav indicator |
| Destructive | `oklch(0.577 0.245 27.325)` | Delete note, remove attachment, destructive confirmations only |

Accent reserved for: primary CTA, active note selection, explicit active navigation state, and the most important inline status or focus treatment. Never use accent for every interactive element.

---

## Visual Hierarchy

- Primary screen layout remains a two-column workspace: notes list on the left, active note detail on the right.
- Focal point is the active note detail panel because Phase 1 must preserve note editing parity while the architecture changes underneath.
- The left column should feel secondary but always visible, with the selected note clearly differentiated from the rest of the list.
- Attachment management sits below or within the active note detail as tertiary content, never competing visually with note title/body editing.
- Icon-only actions are not part of the Phase 1 baseline. If any are introduced during implementation, they must have visible text labels or accessible tooltip/fallback labeling.

## Copywriting Contract

| Element | Copy |

| Destructive confirmation | Delete Note: Delete this note and all linked attachments? This cannot be undone. Remove Attachment: Remove this attachment from the note? This cannot be undone. |
