## Color

Distribution contract: 60/30/10 across the capture workspace.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `oklch(1 0 0)` | App canvas, primary note detail surface, recording review background |

| Accent (10%) | `oklch(0.214 0.009 43.1)` | Primary recording action, active capture mode, selected note state, explicit save action in review |
| Destructive | `oklch(0.577 0.245 27.325)` | Discard recording, remove saved media, delete note confirmations only |

Accent reserved for: active capture mode tabs, the main recording CTA, the review `Save Recording` action, selected note emphasis, and the strongest focus ring/active-state treatment. Never use accent for every button, every link, or all interactive controls.

## Visual Hierarchy

- The overall desktop layout remains a two-pane workspace: note list on the left, active note detail on the right.
- Within the active note pane, the capture panel is the focal point for this phase, not the metadata form. Capture/import should visually anchor the upper-middle portion of the detail pane.
- The review state must feel like an elevated continuation of the capture panel, not a separate modal flow or a full-screen take-over.
- Saved media cards form the secondary focal layer beneath the capture/review panel. They should feel clearly richer than generic attachments but lighter than the active capture surface.
- Generic file cards remain intentionally simpler than audio/video cards so recorded media receives the strongest emphasis.
- Icon-only actions are not part of the default Phase 2 contract. If an icon is used, it must have adjacent visible text or an accessible labeled fallback.

---

## Interaction Contract

- Capture and import live inside the existing attachment area of the active note workspace. They do not open a separate recorder page.
- If the user starts capture/import without a selected note, the workspace should immediately create and focus a new placeholder note, then render the capture/import surface inside that note.
- Capture mode selection should use a compact three-option segmented control or tabs: `Audio`, `Video`, `Video + Audio`.
- The primary flow is:
  1. Start capture or choose import.
  2. If recording, stop capture into review state.
  3. Save or discard the review artifact.
  4. Render the saved artifact as a media card in the note.
- Permission/device failures stay inline in the capture panel and do not block note editing or import actions elsewhere in the pane.
- Saved audio/video cards should expose basic preview/play affordances only. No trimming, waveform editing, retakes, or advanced timeline UI belongs in Phase 2.

---

## Component Contract

- Use shadcn official blocks only for this phase.
- Preferred official blocks:
  - `button` for primary/secondary/destructive actions
  - `card` for capture shell, review surface, and saved media cards
  - `tabs` for capture mode switching
  - `alert` for inline permission/device failures
  - `badge` for media-type labels
  - `input` and `select` for import metadata and any lightweight file-context controls that remain in the existing workspace
  - `separator` for spacing division between capture and saved media sections
- Do not introduce third-party registry blocks for Phase 2 capture surfaces.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Start Recording |
| Secondary CTA | Import Files |
| Audio mode label | Audio |
| Video mode label | Video |
| Combined mode label | Video + Audio |
| Review save CTA | Save Recording |
| Review discard CTA | Discard Recording |
| Empty state heading | Capture Your First Note |
| Empty state body | Start a recording or import files to create a note and keep the media stored locally. |
| Error state | Camera or microphone access is unavailable. Check device permissions, then retry or switch to import. |
| Destructive confirmation | Discard Recording: Discard this unsaved recording? This cannot be undone. Remove Media: Remove this saved media from the note? This cannot be undone. Delete Note: Delete this note and all linked media? This cannot be undone. |

Copy rules:
- Never use bare `Save`, `Cancel`, `Submit`, or `OK` as the visible label for Phase 2 capture flows.
- The save/discard pair must always be noun-specific (`Save Recording`, `Discard Recording`) in review state.
- Permission errors must name the problem and present a next step.
