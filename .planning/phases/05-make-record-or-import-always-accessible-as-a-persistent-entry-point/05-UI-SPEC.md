## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`text-sm`) | 400 (regular) | 1.43 (`leading-5`) |
| Label | 14px (`text-sm`) | 600 (`font-semibold`) | 1.0 (single line) |
| Heading | 20px (`text-xl`) | 600 (`font-semibold`) | 1.2 (`leading-[1.2]`) |
| Display | 28px (`text-[28px]`) | 600 (`font-semibold`) | 1.1 (`leading-[1.1]`) |

Notes:
- Only two weights used across the entire codebase: 400 (default) and 600 (`font-semibold`). This constraint applies to Phase 5.
- Body copy that needs slightly more breathing room uses `leading-6` (16px line height at 16px font — `text-base leading-6`). Use this for the capture panel subline only.
- Uppercase labels use `tracking-[0.12em]` or `tracking-[0.16em]` per the existing eyebrow pattern (e.g., the "PRIVANOTE" app eyebrow and note type labels).

Source: Direct extraction from `App.jsx` lines 914, 917, 935, 961, 983, 1083, 1125, 1147, 1172, 1277–1281.

## Layout Contract

### Sidebar `<aside>` — Phase 5 Target Structure

```
<aside class="rounded-[28px] border bg-secondary/70 p-6 shadow-sm flex flex-col gap-0">
  [Capture Panel]          ← renderCapturePanel() always visible at top
  [Notes Section Header]   ← "Notes" heading + count, mt-6 mb-4
  [Notes List]             ← flex-1 overflow-y-auto, independently scrollable
</aside>
```

- The `<aside>` uses `flex flex-col` so the notes list can take `flex-1 overflow-y-auto` and scroll independently of the capture panel.
- The capture panel stays pinned at top — it does not scroll with the notes list.
- The outer grid constraint `lg:grid-cols-[minmax(320px,380px)_minmax(0,1fr)]` is unchanged (D-04).

### Capture Panel — Sidebar Variant

The capture panel (`renderCapturePanel()`) renders in the sidebar context with these specifications:

- Container: `rounded-[28px] bg-secondary/70 p-6` — matches existing capture panel style from App.jsx line 912.
- Heading: Single static label **"Capture"** at `text-xl font-semibold leading-[1.2]`. Remove the `selectedNode`-conditional heading logic entirely.
- Subline: **"Start a recording or import a file — a note is created automatically."** at `text-sm text-muted-foreground` with `leading-6`.
- Mode selector: Inline pill row (`inline-flex flex-wrap gap-2 rounded-2xl bg-background p-2`) — same as existing, no expansion area.
- Mode buttons: `h-11` (44px) touch target, three options: Audio / Video / Video + Audio.

### Right Panel `<section>` — Empty State

When no note is selected, the right panel shows a minimal empty state placeholder (no capture panel):

- Container: `grid min-h-[520px] content-center` — same grid centering as the removed capture panel wrapper.
- Copy: Heading **"Select a note to view it"** at `text-xl font-semibold` + body **"Capture a recording or import a file from the sidebar to create your first note."** at `text-sm text-muted-foreground leading-6`.
- No action buttons in this placeholder — the capture action is in the sidebar.

Source: RESEARCH.md anti-patterns section ("Don't leave dead state variables", "Don't remove the empty-state placeholder").

## Interaction Contract

| Interaction | Trigger | Result |
|-------------|---------|--------|
| Select capture mode | Click mode button (Audio / Video / Video + Audio) in sidebar capture panel | Active mode button gets `--primary` fill; inactive buttons revert to transparent with `text-muted-foreground` |
| Start recording | Click "Start Recording" in sidebar capture panel | Recording begins; panel enters recording state; works regardless of which note is selected or whether any note exists |
| Save recording | Click "Save Recording" in review state | `ensureCaptureNode()` auto-creates note if none selected; media saved; app navigates to the created note's detail view immediately |
| Import file | Click "Import File" / trigger file picker | File picked; `ensureCaptureNode()` auto-creates note; media saved; app navigates to created note detail view immediately |
| Select note from list | Click note card in sidebar notes list | Right panel shows note detail (title, description, tags edit form + transcript + media) |
| No note selected | Default state on launch or after deselect | Right panel shows the empty state placeholder copy (no capture panel) |

Source: CONTEXT.md D-01, D-03, D-05, D-07; RESEARCH.md patterns section.
