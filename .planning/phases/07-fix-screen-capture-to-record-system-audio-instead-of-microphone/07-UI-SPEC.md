### Copy Rationale

- The existing `captureFailureCopy` constant in App.jsx ("Camera or microphone access is unavailable. Check device permissions, then retry or switch to import.") must be updated or supplemented with screen-recording-specific messaging per D-10/D-11/D-12.
- The error banner uses the existing pattern: `rounded-2xl border border-destructive/20 bg-destructive/10 px-4 py-3 text-sm text-destructive` -- no visual change, only copy change.
- After two denials (D-12), the copy shifts from "click Record to try again" to directing the user to macOS System Settings, since the app will no longer re-prompt automatically.

## Interaction Contract

This phase has **no new UI components** (D-04: "No additional UI indicator for system audio capture -- the interface stays unchanged"). The design contract covers only the changed error/permission states.

### Permission Flow States

| State | Trigger | UI Behavior |
|-------|---------|-------------|
| Permission not yet requested | User clicks Record for the first time | macOS system permission dialog appears. No app-level UI change until grant/denial. |
| Permission granted | User approves macOS prompt | Recording starts normally. No visual difference from current behavior. |
| Permission denied (first time) | User denies macOS prompt | Recording does not start. Error banner appears with "denied (first denial)" copy. Next Record click will re-prompt once. |
| Permission denied (second time) | User denies macOS prompt again | Recording does not start. Error banner appears with "blocked (after two denials)" copy. Further Record clicks show the blocked message without re-prompting. |
| Permission restored | User grants via macOS System Settings | Next Record click succeeds normally. Error banner clears. |

### Unchanged Elements

The following UI elements remain exactly as they are today:

- Record button appearance, position, and label
- Capture mode selector (Audio, Video, Video+Audio)
- Recording timer and stop button
- Review screen after recording
- Save/discard flow
- All sidebar layout and spacing
