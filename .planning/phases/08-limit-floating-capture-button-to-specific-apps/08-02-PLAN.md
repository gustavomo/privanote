3. Add toggle handler:
```javascript
function handleToggleCaptureApp(appId) {
  const updated = { ...captureApps, [appId]: !captureApps[appId] };
  setCaptureApps(updated);
  // Save immediately via IPC -- no need to wait for "Save Settings" button
  // because the main process needs to know right away for polling decisions
  window.api.updateCaptureApps(updated).catch(() => {});
}
```

Note: The capture apps whitelist saves immediately on toggle (not on "Save Settings" click). This is because the main process needs to start/stop polling immediately. The "Save Settings" button applies to backend-owned settings (storage, transcription, provider). The capture apps whitelist is main-process-owned and independent.
