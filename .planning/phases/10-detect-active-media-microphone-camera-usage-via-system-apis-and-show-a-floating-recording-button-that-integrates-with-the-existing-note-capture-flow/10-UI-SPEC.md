# Phase 10 — UI Design Contract

> Visual and interaction contract for the conditional call-recording button on the floating overlay. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (overlay is self-contained HTML -- no shadcn components used in this surface) |
| Preset | radix-nova / taupe / cssVariables / oklch |
| Component library | N/A for overlay -- self-contained HTML with inline styles matching shadcn tokens |
| Icon library | Lucide (SVG inline in overlay HTML) |
| Font | -apple-system, BlinkMacSystemFont, sans-serif (system font stack -- overlay convention) |

**Note:** The floating overlay (`capture-overlay.html`) is a self-contained HTML file with inline CSS. It does not use Tailwind or shadcn components. All new elements follow the existing inline-style pattern using oklch color values. This phase adds a conditional third button that appears only when external mic/camera usage is detected.

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Pulse ring inset offset |
| sm | 8px | Gap between buttons in vertical stack |
| md | 16px | Not used in overlay |
| lg | 24px | SVG icon size inside buttons |
| xl | 32px | Not used in overlay |
| 2xl | 48px | Not used in overlay |
| 3xl | 64px | Overlay container width per button column slot |

Exceptions:
- Overlay container body expands dynamically: `64x136` (2 buttons) to `64x208` (3 buttons) when a call is detected. Formula: `N * 64 + (N-1) * 8` where N = button count.
- Button diameter remains 56px (existing pattern from Phase 6).
- Touch target minimum 44px is satisfied by the 56px button.
- The third button slides in at the bottom of the stack with a 200ms ease-out transition.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `transparent` | Overlay body background |
| Secondary (30%) | `oklch(0.214 0.009 43.1)` | Button idle background (all three buttons) |
| Accent (10%) | `oklch(0.55 0.20 145)` | Call recording button active state only |
| Destructive | `oklch(0.577 0.245 27.325)` | Screen capture recording state only (existing) |

Accent reserved for: Call recording button active/recording state background only. The green accent (`oklch(0.55 0.20 145)`) evokes the universal "active call" metaphor and is visually distinct from red (screen capture) and blue (clipboard monitoring).

### Button Color Map (All Three Overlay Buttons)

| State | Capture Button | Clipboard Button | Call Recording Button |
|-------|---------------|-----------------|----------------------|
| Idle | `oklch(0.214 0.009 43.1)` | `oklch(0.214 0.009 43.1)` | `oklch(0.214 0.009 43.1)` |
| Hover | `oklch(0.35 0.012 43.1)` | `oklch(0.35 0.012 43.1)` | `oklch(0.35 0.012 43.1)` |
| Active | `oklch(0.577 0.245 27.325)` (red) | `oklch(0.488 0.243 264.376)` (blue) | `oklch(0.55 0.20 145)` (green) |
| Finalizing | `oklch(0.547 0.021 43.1)` (muted) | `oklch(0.547 0.021 43.1)` (muted) | `oklch(0.547 0.021 43.1)` (muted) |

### Pulse Ring Color

| Button | Pulse Color |
|--------|-------------|
| Screen capture | `oklch(0.577 0.245 27.325)` (red) |
| Clipboard | `oklch(0.488 0.243 264.376)` (blue) |
| Call recording | `oklch(0.55 0.20 145)` (green) |

### Call-Ended-While-Recording Indicator

When the external call ends but Privanote is still recording, the call recording button transitions to amber to signal the call source is gone:

| State | Color | Meaning |
|-------|-------|---------|
| Recording + call active | `oklch(0.55 0.20 145)` (green) | Normal recording |
| Recording + call ended | `oklch(0.75 0.18 85)` (amber) | Call ended, recording continues |

The amber state uses a 300ms crossfade transition. The pulse ring also switches to amber. Button remains clickable to stop recording.

## Component Inventory

### New Elements (added to capture-overlay.html)

1. **Call recording button** (`#callBtn`, `.btn.call-recording`)
   - 56px diameter circle, identical shape to existing buttons
   - Positioned below the clipboard button with 8px vertical gap
   - Icon: Lucide `headphones` SVG (idle/ready) / stop square SVG (recording) / spinner SVG (finalizing)
   - Conditionally visible: only rendered when main process reports active external media usage
   - Click starts/stops call recording using existing mixed audio flow
   - `aria-label`: dynamic, includes app name (e.g., "Record Zoom call" / "Stop Zoom recording")

2. **Call pulse ring** (`.call-pulse`)
   - Same animation keyframes as existing pulse rings
   - Green color: `oklch(0.55 0.20 145)`
   - Switches to amber `oklch(0.75 0.18 85)` when call ends during recording
   - Visible only during active call recording

### Modified Elements

3. **Overlay container** (`.container`)
   - Dynamic height: `136px` (2 buttons, no call) or `208px` (3 buttons, call detected)
   - Transition: `height 200ms ease-out` for smooth expansion/contraction
   - `flex-direction: column` with `gap: 8px` (unchanged)

4. **Overlay BrowserWindow** (in main.js)
   - Dynamic resize: `overlayWindow.setSize(64, newHeight)` when call detection state changes
   - Height values: 136 (no call) or 208 (call detected)
   - Resize must not move the overlay's top-left anchor position

5. **Body element**
   - Dynamic height matching container: `136px` or `208px`
   - Transition: `height 200ms ease-out` matching container

### Interaction States

| Interaction | Call Recording Button Behavior |
|-------------|-------------------------------|
| Call detected (button appears) | Slide in from bottom over 200ms, idle state, headphone icon |
| Click (idle, call active) | Start recording -> green background, pulse ring, stop-square icon |
| Click (recording) | Stop recording -> finalizing state, spinner icon, create note |
| Click (finalizing) | Disabled, spinner icon, cursor: default |
| Hover (idle) | Scale 1.06, lighter background (same as other buttons) |
| Call ends (not recording) | Button slides out over 200ms, overlay contracts to 136px |
| Call ends (while recording) | Button stays visible, transitions to amber state, recording continues |
| Recording stopped after call ended | Finalizing -> button removed, overlay contracts to 136px |

### Visibility Logic

| Condition | Button Visible | Overlay Height |
|-----------|---------------|----------------|
| No external media detected | No | 136px (2 buttons) |
| External mic/camera active, not recording | Yes (idle) | 208px (3 buttons) |
| External mic/camera active, recording | Yes (green active) | 208px (3 buttons) |
| External media ended, still recording | Yes (amber active) | 208px (3 buttons) |
| Recording finalized after call ended | Removed after finalize | 136px (2 buttons) |

### IPC Bridge Methods (preload)

| Method | Direction | Purpose |
|--------|-----------|---------|
| `window.captureApi.onMediaDetected(cb)` | main -> renderer | Notify overlay that external media is active, includes app name |
| `window.captureApi.onMediaEnded(cb)` | main -> renderer | Notify overlay that external media stopped |
| `window.captureApi.startCallRecording()` | renderer -> main | Start mixed audio recording for detected call |
| `window.captureApi.stopCallRecording()` | renderer -> main | Stop call recording, create note |
| `window.captureApi.onCallRecordingState(cb)` | main -> renderer | State updates: idle/recording/finalizing |
| `window.captureApi.getMediaState()` | renderer -> main | Get current media detection state on overlay load |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (idle, call detected) | "Record {AppName} call" (aria-label + title, e.g., "Record Zoom call") |
| Primary CTA (recording) | "Stop {AppName} recording" (aria-label + title) |
| Primary CTA (recording, call ended) | "Stop recording (call ended)" (aria-label + title) |

| Empty state heading | N/A -- button is hidden when no call detected |
| Empty state body | N/A |
| Error state | N/A for overlay -- detection errors are logged to console only |
| Note title (generated) | "{AppName} call -- {Mon DD}, {h:mm AM/PM}" (e.g., "Zoom call -- Apr 1, 2:30 PM") |
| Note title (unknown app) | "Call recording -- {Mon DD}, {h:mm AM/PM}" |
| Destructive confirmation | None -- stopping recording auto-creates note without confirmation (consistent with D-06) |

## Keyboard Shortcuts

| Shortcut | Action | Source |
|----------|--------|--------|
| None | Call recording has no global shortcut -- button only appears contextually when a call is detected | D-05, D-06 |
| Cmd+Shift+R | Toggle screen capture (existing) | Existing |
| Cmd+Shift+V | Toggle clipboard monitoring (existing) | Phase 9 |

No keyboard shortcut is assigned for call recording. The button is inherently contextual (only visible during detected calls), and adding a shortcut for a conditional action would create confusion when no call is active.
