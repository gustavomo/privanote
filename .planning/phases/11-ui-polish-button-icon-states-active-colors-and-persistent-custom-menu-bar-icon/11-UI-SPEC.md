# Phase 11 — UI Design Contract

> Visual and interaction contract for the overlay button polish, unified active color, icon state changes, menu bar icon, and minimize-to-tray behavior. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn |
| Preset | radix-nova (taupe base, cssVariables: true) |
| Component library | radix (via shadcn) |
| Icon library | lucide (main app); inline SVG (overlay — self-contained HTML, no bundler) |
| Font | Inter Variable (main app); -apple-system (overlay — system font only) |

> Note: The overlay (`capture-overlay.html`) is a self-contained HTML file with no Tailwind or shadcn. All overlay styling is raw CSS with oklch values. The design tokens below apply to the overlay's inline styles. The main app's shadcn tokens are not modified by this phase.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Gap between overlay buttons (D-02) |
| sm | 8px | Badge offset, button shadow spread |
| md | 16px | Badge internal size (badge diameter) |
| lg | 24px | Not used in this phase |
| xl | 32px | Not used in this phase |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Overlay button diameter: 40px (D-01, not a spacing token — a component dimension)
- Mode picker button diameter: 34px (D-01 proportional scaling from 48px)
- Touch/click target: 40px meets macOS minimum click target; no additional padding needed for desktop-only overlay
- Badge diameter at 40px button: 16px (scaled from 20px at 56px, positioned top: -2px, right: -2px)

### recalcHeight() update

Formula changes from `count * 64 + 8` to `count * 44 + 4`:
- Each button row: 40px button + 4px gap = 44px
- Mode picker: 2 buttons at 34px + 6px gap + 4px spacing = 78px (was 108px)

## Icon States Contract

### Screen Capture Button (`#btn`)

| State | Icon | Description | SVG Concept |
|-------|------|-------------|-------------|
| idle | eye-closed | Eye with a diagonal line through it | Closed eye path with strike-through line (D-04) |
| recording (active) | eye-open | Open eye, clearly "seeing" | Open eye path with pupil circle — current idle icon reused (D-04) |
| finalizing | spinner | Rotating loader | Existing spinner paths (unchanged) |

### Clipboard Button (`#clipBtn`)

| State | Icon | Description | SVG Concept |
|-------|------|-------------|-------------|
| idle | clipboard-closed | Flat clipboard, no content indicator | Clipboard outline only, no checkmark (D-05) |
| monitoring (active) | clipboard-open | Clipboard with writing/content | Clipboard with lines or pencil indicating active capture (D-05) |
| finalizing | spinner | Rotating loader | Existing spinner paths (unchanged) |

### Call Recording Button (`#callBtn`)

| State | Icon | Description | SVG Concept |
|-------|------|-------------|-------------|
| idle | headphones-off | Headphones with a mute slash | Headphones path with diagonal strike-through line (D-06) |
| recording (active) | headphones-on | Active headphones | Clean headphones icon, no strike (D-06) — current idle icon reused |
| amber | headphones-on | Same active icon, amber color | Same SVG as recording, color change signals call-ended (D-07) |
| finalizing | spinner | Rotating loader | Existing spinner paths (unchanged) |

### Key change: no stop-square icons

All three buttons previously showed a stop-square (`<rect>`) when active. This phase removes all stop-square icons. The icon itself changes to an "active" variant (eye-open, clipboard-writing, headphones-on) combined with the teal background color. Clicking toggles back to idle. (D-04, D-05, D-06)

## Menu Bar Icon Contract

### Tray Icon (D-12, D-13, D-14)

| State | Icon | Title Text | Tooltip |
|-------|------|-----------|---------|
| idle | Monochrome "P" lettermark template image (16x16 @1x, 32x32 @2x) | (none) | "Privanote Capture" |
| recording | Same "P" lettermark with small red dot badge (bottom-right) | (none) | "Privanote -- Recording..." |

Implementation:
- Create a 16x16 PNG (+ @2x 32x32) of the lettermark "P" glyph
- Use `nativeImage.createFromBuffer()` with `setTemplateImage(true)` so macOS adapts to light/dark menu bar automatically (D-13)
- For recording state: create a second PNG variant with a 4px red filled circle at bottom-right of the glyph (D-14)
- Remove `tray.setTitle('...')` calls entirely — no more emoji text in menu bar (D-12)
- Dock badge "REC" behavior remains unchanged

| recording | "Recording..." (disabled) / "Stop Capture" / separator / "Show Privanote" / "Quit Privanote" |

## Window Close Behavior Contract

### Minimize to Tray (D-15, D-16, D-17)

| Event | Current Behavior | New Behavior |
|-------|------------------|--------------|
| User clicks window close (X) | Window destroyed, `window-all-closed` fires | `mainWindow.on('close')` intercepted: `event.preventDefault()`, `mainWindow.hide()`. Window hidden, NOT destroyed. |
| `app.on('window-all-closed')` | Stops detection, destroys sessions, shuts down backend | No longer fires during normal use (window is hidden, not closed). Remains as safety fallback. |
| Cmd+Q / `app.quit()` | Quits normally | Set `isQuitting = true` flag in `app.on('before-quit')`. Close handler checks flag: if true, allows destroy. Tray removed on quit. (D-16) |
| Click tray icon | N/A (tray existed but no click handler for show) | `tray.on('click', () => mainWindow.show())` — reopens/focuses main window (D-17) |
| "Show Privanote" menu item | Shows window | Shows window (unchanged) |
| "Quit Privanote" menu item | N/A | `app.quit()` — full quit including backend shutdown |

### Session Continuity

Overlay window, capture sessions, clipboard sessions, and app detection polling continue running when the main window is hidden. They are only destroyed on actual app quit.

## Pulse Animation Removal (D-11)

Remove entirely:
- `.pulse` element and `.recording .pulse` rule
- `.clipboard-pulse` element and `.monitoring .clipboard-pulse` rule
- `.call-pulse` element and `.call-recording .call-pulse` / `.call-amber .call-pulse` rules
- `@keyframes pulse`, `@keyframes clipboard-pulse`, `@keyframes call-pulse`

The color change from idle (dark charcoal) to active (teal) is sufficient state indication at the smaller 40px size. This removes 6 CSS rules, 3 keyframe animations, and 3 HTML elements.
