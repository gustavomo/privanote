    **Migration 1: Workspace/Settings tab switcher (~line 1518-1543).**
    Replace the current `<div className="inline-flex rounded-2xl bg-secondary p-2">` with custom buttons to a shadcn ToggleGroup. The current implementation uses custom `renderToggleIndicator`, `aria-pressed`, `data-state`, and active classes with shadow, ring-2, and -translate-y-px. Since these custom styles are part of the design language, keep the custom styling approach but use ToggleGroup for accessibility (roving tabindex, arrow key navigation):

    ```jsx
    <ToggleGroup
      type="single"
      value={activeView}
      onValueChange={(value) => {
        if (value) setActiveView(value);
      }}
      className="inline-flex rounded-2xl bg-secondary p-2"
    >
      {['Workspace', 'Settings'].map((label) => {
        const value = label.toLowerCase();
        const isActive = activeView === value;

        return (
          <ToggleGroupItem
            key={label}
            value={value}
            aria-current={isActive ? 'page' : undefined}
            className={cn(
              'inline-flex h-11 items-center justify-center gap-2 rounded-xl border px-4 text-sm font-semibold transition-all duration-200',
              isActive
                ? 'border-primary bg-primary text-primary-foreground shadow-[0_18px_42px_-22px_rgba(15,23,42,0.95)] ring-2 ring-primary/20 -translate-y-px'
                : 'border-transparent text-muted-foreground hover:bg-background hover:text-foreground'
            )}
          >
            {renderToggleIndicator(isActive)}
            <span>{label}</span>
          </ToggleGroupItem>
        );
      })}
    </ToggleGroup>
    ```
