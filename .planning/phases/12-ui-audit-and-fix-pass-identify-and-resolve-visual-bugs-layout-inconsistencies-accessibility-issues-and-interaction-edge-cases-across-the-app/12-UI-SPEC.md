## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps within buttons, inline padding |
| sm | 8px | Compact element spacing, gap between badge pills |
| md | 16px | Default padding inside cards and form groups (p-4) |
| lg | 24px | Section padding inside grouped panels (p-6) |
| xl | 32px | Gap between major layout sections (gap-8) |
| 2xl | 48px | Unused in this phase |
| 3xl | 64px | Unused in this phase |

Exceptions:
- Touch targets: All interactive buttons use h-10 (40px) or h-11 (44px) minimum height. h-11 is the standard for form-level buttons; h-10 for inline/card-level actions.
- Sidebar aside padding: 24px (p-6) consistent with existing pattern.
- Main page padding: px-6 py-8 (24px horizontal, 32px vertical) on the root `<main>`.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (text-sm) | 400 (normal) | 1.5 (leading-6 at 14px) |
| Label | 14px (text-sm) | 600 (font-semibold) | 1.43 (default) |
| Heading | 20px (text-xl) | 600 (font-semibold) | 1.2 (leading-[1.2]) |
| Display | 28px (text-[28px]) | 600 (font-semibold) | 1.1 (leading-[1.1]) |

Additional typography rules:
- Overline/eyebrow text: 14px, 600 weight, uppercase, tracking-[0.16em], color muted-foreground.
- Font family: `'Inter Variable', sans-serif` applied via `html` selector and `--font-sans` CSS variable.
- No additional fonts or weights beyond 400 and 600.

Accent reserved for: Primary action buttons (Start Recording, Save Recording, Save Changes, Save Settings, Connect provider, Retry Sync), selected note item in sidebar, active Workspace/Settings tab, active capture mode tab, "Connected" status badge, "Default destination" badge.

### Dark Mode Toggle Strategy

- Use class-based dark mode: add `darkMode: 'class'` to `tailwind.config.js`.
- Toggle adds/removes `.dark` class on the `<html>` element.
- Persist preference to localStorage key `privanote-theme` with values: `light`, `dark`, `system`.
- Default to `system` (respect `prefers-color-scheme` media query).
- Place toggle in the Settings view as a new "Appearance" section at the top of the settings panel, before "Cloud sync".

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| Color contrast | All text on background surfaces meets WCAG 2.1 AA (4.5:1 for body text, 3:1 for large text). oklch(0.547) muted-foreground on oklch(1) background = ~4.7:1 ratio. |
| Keyboard navigation | All interactive elements reachable via Tab. shadcn components provide this by default. |
| Focus indicators | Focus-visible ring on all buttons, inputs, checkboxes, radio buttons. Never remove outline without replacement. |
| Screen reader | `aria-pressed` on toggle buttons (existing). `aria-current="page"` on active tab (existing). Labels on all form inputs via `<label>` or `aria-label`. |
| Motion | No animations that play longer than 200ms. Transition durations use duration-200. No auto-playing motion. |
| Dark mode | prefers-color-scheme respected when theme preference is "system". |
