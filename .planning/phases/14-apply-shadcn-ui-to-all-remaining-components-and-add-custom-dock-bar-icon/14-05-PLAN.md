  <name>Task 1: Fix Progress indeterminate animation and AlertDialog CSS scoping</name>
  <files>apps/desktop/src/renderer/components/ui/progress.jsx, apps/desktop/src/renderer/index.css, apps/desktop/src/renderer/components/ui/alert-dialog.jsx</files>
  <action>
  Three CSS/component fixes:

  **Fix 1 — Progress bar (progress.jsx):**
  The inline `style={{ transform: ... }}` on line 22 overrides the CSS `@keyframes indeterminate` animation because inline styles have higher specificity than keyframe transforms. When `value` is undefined (indeterminate mode), the expression evaluates to `translateX(-100%)` which pins the indicator off-screen permanently.

  Fix: Conditionally apply the inline style ONLY when `value` is defined (determinate mode). When `value` is undefined/null, omit the style attribute entirely so the CSS `.progress-indeterminate` animation in index.css can take control.

  Change line 22 from:
  ```jsx
  style={{ transform: `translateX(-${100 - (value || 0)}%)` }}
  ```
  to:
  ```jsx
  style={value != null ? { transform: `translateX(-${100 - (value || 0)}%)` } : undefined}
  ```

  **Fix 2 — Font variable scoping (index.css):**
  Move `--font-heading` and `--font-sans` from the `.theme` selector to `:root` so that Radix UI portals (which render into `document.body`, outside the `<main class="theme">` element) inherit the correct font variables.

  In index.css, move lines 10-11 from inside `.theme { }` to inside `:root { }`. The `.theme` selector block can be removed entirely if it has no other declarations. Add the two variables right at the top of the `:root` block:
  ```css
  :root {
    --font-heading: 'Inter Variable', sans-serif;
    --font-sans: 'Inter Variable', sans-serif;
    /* ... existing color vars ... */
  }
  ```
  Note: Previously `--font-heading` referenced `var(--font-sans)`, but since both resolve to the same value, set both directly to avoid circular reference issues.

  **Fix 3 — AlertDialog overlay and width (alert-dialog.jsx):**
  - Line 33: Change overlay from `bg-black/10` to `bg-black/50` so the backdrop is clearly visible as a dark overlay.
  - Line 52: Change content max-width from `data-[size=default]:max-w-xs data-[size=default]:sm:max-w-sm` to `data-[size=default]:max-w-md data-[size=default]:sm:max-w-lg` so the dialog has adequate width for confirmation text.
  </action>
