  Two fixes to apps/desktop/scripts/generate-icon.mjs:

  **Fix 1 — SVG artwork sizing (lines 17-20):**
  Resize the artwork to occupy ~80% of the 1024x1024 canvas (~820px) centered with ~102px padding on each side. This follows macOS Human Interface Guidelines for dock icon sizing.

  Change the SVG to:
  ```svg
  <svg xmlns="http://www.w3.org/2000/svg" width="1024" height="1024" viewBox="0 0 1024 1024">
    <rect x="102" y="102" width="820" height="820" rx="180" fill="#1e2028"/>
    <path d="M370 280h180c100 0 180 80 180 180s-80 180-180 180h-80v104h-100V280zm100 264h80c44 0 80-36 80-84s-36-80-80-80h-80v164z" fill="white" transform="translate(0, 52)"/>
  </svg>
  ```

  Key changes:
  - The `<rect>` moves from `x=0 y=0 width=1024 height=1024 rx=228` to `x=102 y=102 width=820 height=820 rx=180`. The rx is proportionally reduced (228 * 820/1024 = ~182, rounded to 180).
  - The `<path>` for the "P" lettermark needs to be recentered within the smaller rect. The original path occupies roughly x=370..630, y=280..744. The rect's horizontal center is now 102+410=512 (same as before) so the P is already horizontally centered. Vertically, the rect runs from y=102 to y=922 (center at 512). The P runs from y=280 to y=744, height 464, center at 512 — already centered. Apply `transform="translate(0, 52)"` to shift the P down slightly to visually center it within the new rect bounds (accounting for the rect starting at y=102 instead of y=0).

  IMPORTANT: The area outside the rounded rect MUST be transparent (no background element in the SVG). The SVG background is inherently transparent since no fill covers the full canvas.

  **Fix 2 — SVG-to-PNG conversion (line 29):**
  Replace `qlmanage` with `rsvg-convert` which is available on this system at `/opt/homebrew/bin/rsvg-convert` (version 2.61.3). rsvg-convert properly preserves SVG alpha transparency.

  ```javascript
  const pngPath = path.join(resourcesDir, 'icon.png');
  execSync(`rsvg-convert -w 1024 -h 1024 "${svgPath}" -o "${pngPath}"`);
  ```

  This is simpler — no renaming needed since rsvg-convert outputs directly to the specified path. Remove the qlmanage output rename logic (the `icon.svg.png` → `icon.png` rename at lines 31-34).
