## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps within buttons (gap-1), inline padding |
| sm | 8px | Compact element spacing, gap between badge pills, toast internal padding |
| md | 16px | Default padding inside cards and form groups (p-4), toast container padding |
| lg | 24px | Section padding inside grouped panels (p-6), skeleton block height |
| xl | 32px | Gap between major layout sections (gap-8) |
| 2xl | 48px | Unused in this phase |
| 3xl | 64px | Unused in this phase |

Exceptions:
- Touch targets: All interactive buttons use h-10 (40px) or h-11 (44px) minimum height. h-11 for form-level buttons; h-10 for card-level inline actions.
- Sidebar aside padding: 24px (p-6) consistent with existing pattern.
- Main page padding: px-6 py-8 (24px horizontal, 32px vertical) on the root `<main>`.
- Icon size within buttons: 16px (size-4, the shadcn default for `[&_svg:not([class*='size-'])]:size-4`).
- Skeleton heights: 20px for text lines, 40px for heading lines, 80px for card placeholders.

## Dock Icon Contract (per D-13, D-14)

### Design Specification

- Shape: macOS rounded-rectangle (squircle), matching system dock icon shape.
- Background: Solid dark charcoal fill. oklch(0.235 0.006 260) matching the new dark mode background. Fallback hex: #1e2028.
- Foreground: White bold "P" lettermark, centered. Font: Inter Bold or system sans-serif bold. The P occupies approximately 55-60% of the icon height for visual prominence.
- No gradients, no shadows, no gloss effects. Flat professional look that pairs with the monochrome tray icon.

### Required Sizes

| File | Size | Format | Purpose |
|------|------|--------|---------|
| icon.icns | 16, 32, 64, 128, 256, 512, 1024px | Apple Icon Image | macOS dock + Finder |
| icon.ico | 16, 32, 48, 256px | Windows ICO | Windows taskbar (future) |
| icon.png | 1024x1024px | PNG | Fallback, Linux, about dialog |

### File Location

Place all icon files in `apps/desktop/resources/`:
- `apps/desktop/resources/icon.icns`
- `apps/desktop/resources/icon.ico`
- `apps/desktop/resources/icon.png`

### Wiring

In `apps/desktop/src/main/main.js`, update BrowserWindow creation to include:
```js
icon: path.join(__dirname, '..', '..', 'resources', 'icon.png')
```

In electron-builder config (package.json or electron-builder.yml), set:
```json
{
  "mac": { "icon": "resources/icon.icns" },
  "win": { "icon": "resources/icon.ico" },
  "linux": { "icon": "resources/icon.png" }
}
```

### Generation Method

Use programmatic SVG-to-PNG pipeline:
1. Create `scripts/generate-icon.mjs` that renders an SVG with the P lettermark onto a canvas.
2. Use `sharp` (or `canvas`) to export 1024x1024 PNG.
3. Use `png2icons` or `electron-icon-builder` to generate .icns and .ico from the PNG.
4. Alternatively, create the SVG manually and use an online converter. The executor chooses the tooling.

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| Color contrast | All text on background surfaces meets WCAG 2.1 AA (4.5:1 for body text, 3:1 for large text). Dark mode: oklch(0.93) foreground on oklch(0.235) background exceeds 4.5:1. |
| Keyboard navigation | All interactive elements reachable via Tab. AlertDialog traps focus. Toast is aria-live="polite". |
| Focus indicators | Focus-visible ring on all buttons, inputs, checkboxes, radio buttons. ring color uses --ring (blue in dark mode). |
| Screen reader | `aria-pressed` on toggle buttons (existing). `aria-current="page"` on active tab. Labels on all form inputs. Tooltips provide aria-label for icon-only buttons. AlertDialog uses role="alertdialog" with aria-describedby. |
| Motion | No animations exceed 200ms except skeleton pulse (2s, subtle opacity only -- prefers-reduced-motion disables it). Toast enter/exit under 200ms. |
| Dark mode | prefers-color-scheme respected when theme preference is "system". |
| Tooltip | Tooltip shows on hover (500ms delay) and on focus. Accessible name provided for icon-only buttons. |
