# Quick Task 260408-7nz: Add loading states and animations to all action buttons

## Goal

Every async action button in the Privanote desktop app must (a) show a spinner while its handler is running, (b) be disabled during execution, (c) have subtle hover/active micro-animations, and (d) respect `prefers-reduced-motion`.

## Must-haves

- Button component accepts `loading` (bool) and `loadingText` (optional string) props.
- When `loading=true`, the button is disabled, shows a spinning `Loader2` (lucide-react), and optionally swaps its text for `loadingText`.
- Subtle micro-animations baked into the base variant: `active:scale-[0.98]` and an existing `transition-all` (already present).
- All async handlers wire a `setIsXxx(true)` on entry and `setIsXxx(false)` in finally.
- `prefers-reduced-motion` block in `index.css` neutralises button transforms/transitions.
- No new dependencies.

## Tasks

### Task 1 — Button component

**Files:** `apps/desktop/src/renderer/components/ui/button.jsx`

**Action:**
1. Import `Loader2` from `lucide-react`.
2. Add `loading` and `loadingText` to destructured props.
3. When `asChild` is true, ignore `loading` (pass through unchanged — asChild is for non-button slot targets).
4. When `loading` is true:
   - Force `disabled` attribute.
   - Render `<Loader2 className="size-4 animate-spin" aria-hidden="true" />` as the first child.
   - Hide the original icon children via CSS (wrap text in a span? No — simpler: just prepend the spinner and let existing svg keep its place). Decision: prepend the spinner and hide other `svg` children while loading via a wrapper class `button-loading` that selectors `.button-loading > svg:not(.button-spinner)` → `display: none`.
   - If `loadingText` provided, render it instead of the text children. Text children are tricky because they're mixed with icons — cleanest is: when `loading && loadingText`, render only `[Loader2, <span>{loadingText}</span>]`.
5. Add base class `active:scale-[0.98]` to `buttonVariants` base string (the existing base already has `transition-all` and `active:not-aria-[haspopup]:translate-y-px`).

**Verify:** File parses, existing usages of `<Button>` compile without changes (prop is optional).
