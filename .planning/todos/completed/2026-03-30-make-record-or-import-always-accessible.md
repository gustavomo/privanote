## Problem

The entry point to start a recording or import content is not persistently available — users have to navigate to a specific screen to trigger it. This creates friction for the core creation flow.

## Solution

Add a persistent "Start recording / Import" action (e.g. floating action button, always-visible toolbar item, or bottom bar entry) so the creation point is reachable from anywhere in the app.
